## [3.5.0] - 2026-10-08

### Added

- Add a pyOpenMS 3.5.0 image built with Miniforge 26.1.1-2 and Ubuntu 24.04.
- Include Matplotlib and Seaborn for compatibility with the legacy image.
- Publish the image for `linux/amd64`, the architecture available for pyOpenMS
  3.5.0 in Bioconda.
- Configure publication to the Boutros Lab GitHub Container Registry.
